## SyncPan 是什么？

**SyncPan** 是一款桌面端网盘管理工具，专为百度网盘和夸克网盘用户打造，帮助你更高效地使用网盘。

你可以把它理解为网盘的「效率增强器」——它能自动帮你追更喜欢的资源、批量转存分享链接、批量处理大量文件、搜索全网资源并一键转存，让你从重复的手动操作中解放出来。

支持 Windows、macOS 和 Linux 三大桌面平台，完全免费使用。支持百度网盘转存、夸克网盘批量转存、网盘自动追更、网盘文件批量重命名、网盘批量分享等功能。

## 🦀 技术亮点

- **Rust 核心引擎**：内存安全、天生高并发，转存 / 重命名 / 分享等核心操作全部由 Rust 实现，快且稳
- **Tauri 桌面框架**：相比传统 Electron 方案，安装包更小、内存占用更低、原生体验
- **React + TypeScript 前端**：组件化 UI，深色模式 + 10 种主题配色，流畅交互
- **本地加密存储**：账号 Cookie / Token 使用 AES-256-GCM 加密，密钥由机器指纹派生，数据不出本机
- **风控策略引擎**：三档预设 + 自定义参数，连续失败自动退避、夜间自动降速，保护你的网盘账号
- **局域网服务**：内网穿透 + 访问密码 + 暴力破解防护，手机平板即用

## 功能详解

### 🔄 自动追更 — 百度网盘夸克网盘定时自动转存

把你关注的百度网盘或夸克网盘分享链接设为任务，有新内容时自动转存到你的网盘，省去每天手动检查的麻烦。

**使用场景：**
- 追剧：关注分享链接的更新，新集自动保存到你的网盘
- 合集跟踪：监控系列资源，有新内容自动收集
- 定期同步：设定定时周期，到点自动执行

**功能要点：**
- **定时调度**：支持每天/每周/每月定时执行，也可按分钟/小时间隔运行，高级用户可用 Cron 表达式自定义
- **增量转存**：已转存的文件不会重复保存，只同步新增内容
- **文件过滤**：可选择只保存特定类型文件（如 mp4），排除不需要的内容
- **任务分组**：可将多个分享链接组合成一个「聚合任务」，统一管理、统一调度
- **任务导入导出**：JSON 格式导出和导入任务配置，方便备份或迁移
- **转存日志**：每次执行都有详细记录，成功了哪些、失败了哪些一目了然

<p align="center"><img src="https://syncpan.top/images/docs/af-create-task.png" alt="自动追更-新建任务" width="680" /></p>

### 📂 文件浏览与管理 — 百度网盘夸克网盘文件管理器

在应用内直接浏览和管理网盘中的文件，无需打开网页。支持百度网盘和夸克网盘随时切换。

**使用场景：**
- 整理网盘文件：批量重命名、移动、删除、复制
- 查看文件内容：直接在应用内预览图片和文本文件
- 创建分享链接：选中文件一键生成分享链接和提取码

**功能要点：**
- 目录浏览 + 面包屑路径导航，随时返回上级目录
- 文件操作：重命名、删除、移动、复制、新建文件夹
- 批量多选操作：一次勾选多个文件，批量分享/删除/移动/复制
- 图片预览：点击即可全屏查看，支持前后翻页
- 文本预览：TXT、MD 等文本文件直接在应用内查看前 256KB
- 存储空间：实时显示已用容量和总容量
- 双平台切换：百度网盘和夸克网盘随时切换

### 🔍 资源搜索与发现 — 百度网盘夸克网盘资源搜索

**全网资源搜索**：通过 PanSou 盘搜引擎，搜索百度网盘和夸克网盘全网的分享资源。

- 输入关键词即可搜索全网的网盘分享文件
- 可按百度网盘/夸克网盘筛选结果
- 搜索结果关键词自动标红高亮
- 一键复制分享链接
- 一键「追更」：从搜索结果直接创建自动追更任务
- 一键「转存并分享」：将搜索到的资源保存到自己网盘并生成新的分享链接

<p align="center"><img src="https://syncpan.top/images/docs/sr-main.png" alt="资源搜索界面" width="680" /></p>

**发现页**：浏览豆瓣影视榜单，发现感兴趣的内容。

- 电影热榜、口碑榜、新片榜
- 电视剧热榜、综艺热榜
- 豆瓣高分推荐、冷门佳片
- 从榜单一键跳转到资源搜索，找到对应网盘资源

### 📦 批量转存 — 百度网盘批量转存 / 夸克网盘批量转存

一次性将多条百度网盘和夸克网盘分享链接中的文件批量保存到你的网盘。

**使用场景：**
- 一次性处理几十条分享链接
- 将多个来源的资源统一保存到自己的网盘

**功能要点：**
- 粘贴多行分享链接，自动解析
- 分别选择百度网盘和夸克网盘的目标账号
- 实时进度显示，每条链接的转存结果一目了然
- 支持暂停/继续/取消操作
- 独立的防风控策略，可自定义操作间隔和批次暂停时间

### 🔗 链接转换 — 百度网盘链接互转 / 夸克网盘链接转存分享

将别人的百度网盘或夸克网盘分享链接转存后，用自己账号重新生成新的分享链接。资源整理党/分享者的利器：批量完成链接「换主体」，让资源真正变成自己的。

**使用场景：**
- 把收集到的资源整理后用自己账号重新分享
- 需要统一管理分享链接时使用

**功能要点：**
- 粘贴分享链接，自动解析
- 转存到目标账号后自动重新生成分享链接
- 结果表格展示：源链接 → 新链接
- 支持暂停/继续/取消

### ✏️ 批量重命名 — 百度网盘文件批量改名 / 夸克网盘批量重命名

按规则批量修改百度网盘和夸克网盘中的文件、文件夹名称。支持正则替换、序号命名、添加前后缀、修改扩展名。

**使用场景：**
- 批量删除文件名中的广告文字
- 给剧集文件添加序号
- 统一修改文件扩展名
- 批量添加前缀/后缀

**功能要点：**
- 支持递归子目录，可设置递归深度
- 可按类型筛选（只改文件/只改文件夹/全部）
- 重命名规则：正则替换、文本查找替换、序号命名、添加前后缀、修改扩展名
- 预览面板：先预览重命名结果，确认后再执行
- 支持暂停/继续/取消

### 📢 批量分享 — 百度网盘夸克网盘文件批量生成分享链接

批量给百度网盘和夸克网盘中的文件创建分享链接和提取码。适合资源分享者：整批文件一次生成分享，提取码和有效期统一配置，不必在网页里逐个操作。

**使用场景：**
- 一次性给多个文件生成分享链接
- 需要统一的提取码和有效期时批量设置

**功能要点：**
- 配置待分享的文件路径列表
- 统一设置提取码和有效期天数
- 支持暂停/继续/取消
- 结果面板展示所有生成的分享链接

### 🗂️ 我的分享

查看自己在百度网盘和夸克网盘上创建过的所有分享记录。让「分享出去就忘」的资源变成可查看、可管理、可导出的数据资产。

**使用场景：**
- 查看自己分享过的文件和链接
- 了解分享的浏览、下载、转存数据
- 导出分享记录用于备份

**功能要点：**
- 按平台和账号查看分享记录
- 显示统计数据：总数、浏览量、下载量、转存次数
- 批量获取方式：按页数/按天数/按日期范围
- 真实密码获取（百度网盘隐藏提取码）
- 排序：按浏览量/下载量/转存量/创建时间
- 本地缓存（可设置有效期），避免频繁请求
- 导出 CSV 表格到本地

### 🧹 广告清理与插入

**清理广告**：一键扫描并批量删除网盘中混入的广告文件。

- 选择目录，按关键词匹配广告文件
- 先扫描再确认，确认后才执行删除
- 支持递归子目录，可设置深度
- 支持暂停/继续/取消

**广告插入**：将广告文件批量插入到目标目录中。

- 两种模式：随机插入（分散到子目录）、定向插入（匹配关键词子目录）
- 选择广告文件库 + 目标文件夹
- 极速模式可选，加快插入速度
- 支持暂停/继续/取消

### 🌲 目录树导出

将网盘目录结构生成树形图或列表，导出为文本文件保存到本地。整理或展示大型资源库的利器：一键导出完整目录结构，清晰直观。

**使用场景：**
- 导出网盘目录结构用于整理和记录
- 给他人展示网盘内容结构

**功能要点：**
- 选择目标目录，递归扫描所有子目录
- 两种导出样式：树形（├── └──）和列表（完整路径逐行）
- 扫描进度实时显示
- 默认保存为 TXT 文件，文件名包含网盘、账号、目录名信息
- 文件名冲突时自动添加时间戳

### 🔑 账号管理

统一管理你的百度网盘和夸克网盘账号。

**功能要点：**
- 多账号支持，同时登录和管理多个账号
- 两种登录方式：扫码登录 / 手动粘贴 Cookie
- 卡片视图和列表视图（支持拖拽排序）
- Cookie 有效性验证，失效会提示
- 账号信息展示：头像、用户名、VIP 类型、容量使用
- 夸克网盘每日签到

## 常见问题

### 为什么操作之间有延迟？

网盘平台对频繁操作有风控限制。SyncPan 内置智能风控策略，会在操作之间加入随机等待、批次暂停等保护措施，防止账号被限或封禁。你可以在「设置 → 防风控策略」中调整延迟强度。

### 登录信息保存在哪里？安全吗？

所有账号 Cookie 和 Token 使用 AES-256-GCM 加密后存储在本地，密钥从你的机器指纹派生，不会上传到任何服务器。

### 免费版有什么限制？

SyncPan 免费使用。免费版每平台有账号数量限制，VIP 会员可解锁无限账号和更多定时任务数。

### 支持跨平台同步吗？

SyncPan 是桌面应用，Windows、macOS、Linux 都能用。通过「内网穿透」功能，手机和平板的浏览器也可以在局域网内访问使用。

### 如何自动追更资源？

1. 在「自动追更」页面点击「新建任务」
2. 输入任务名称，设置定时规则（如每天执行一次）
3. 粘贴要监控的分享链接
4. 选择保存目标网盘和目录
5. 任务会在设定时间自动检查更新，有新内容时自动转存
