## SyncPan 是什么？

**SyncPan** 是一款桌面端网盘管理神器，**一次性打通百度、夸克、阿里、UC、123、115、光鸭、移动、天翼、迅雷 10 大主流网盘**，是你管理所有网盘资源的唯一入口。

你可以把它理解为网盘界的「瑞士军刀」——自动追更想看的剧集、批量转存成百上千条分享链接、在任意两个网盘之间直接搬文件、全网搜资源一键入库、批量处理海量文件……那些在网页端要点几十次鼠标才能完成的操作，在这里粘贴一次、点一下就完事。

支持 Windows、macOS 和 Linux 三大桌面平台，核心功能完全免费。无论是百度网盘转存、夸克网盘批量转存、阿里云盘资源整理、115 离线下载管理，还是网盘自动追更、批量重命名、批量分享、跨盘搬家，一个 SyncPan 全部搞定。

## 🦀 技术亮点

- **Rust 核心引擎**：内存安全、天生高并发，转存 / 互传 / 重命名 / 分享等核心操作全部由 Rust 实现，快且稳
- **Tauri 桌面框架**：相比传统 Electron 方案，安装包更小、内存占用更低、原生体验
- **统一平台抽象**：10 家网盘接入同一套服务接口，能力对齐、体验一致，新平台持续接入中
- **自研传输引擎**：Range 断点续传、直链失效自动重取、全局带宽限速、秒传探测优先命中，跨盘搬家又快又省流量
- **React + TypeScript 前端**：组件化 UI，深色模式 + 10 种主题配色，流畅交互
- **本地加密存储**：账号 Cookie / Token 使用 AES-256-GCM 加密，密钥由机器指纹派生（PBKDF2 十万轮），数据不出本机
- **风控策略引擎**：三档预设 + 自定义参数，连续失败自动退避、夜间自动降速，保护你的网盘账号
- **局域网服务**：内网穿透 + 访问密码 + 暴力破解防护，手机平板即用

## 功能详解

### 🔄 自动追更 — 全网盘定时自动转存

把你关注的分享链接设为任务，有新内容时自动转存到你的网盘，省去每天手动检查的麻烦。**百度、夸克、阿里、UC 等 10 大网盘全部支持。**

**使用场景：**
- 追剧：关注分享链接的更新，新集自动保存到你的网盘
- 合集跟踪：监控系列资源，有新内容自动收集
- 定期同步：设定定时周期，到点自动执行

**功能要点：**
- **定时调度**：支持每天/每周/每月定时执行，也可按分钟/小时间隔运行，高级用户可用 Cron 表达式自定义
- **增量转存**：已转存的文件不会重复保存，只同步新增内容
- **文件过滤**：支持 glob / 正则 / 关键词包含与排除，只保存想要的内容（如只留 mp4）
- **聚合任务**：多个分享链接组合成一个任务，统一管理、统一调度，一任务多链接多平台
- **影视元数据**：接入 TMDB，自动匹配剧集海报与季集信息，资源库秒变海报墙
- **任务导入导出**：JSON 格式导出和导入任务配置，方便备份或迁移
- **转存日志**：每次执行都有详细记录，成功了哪些、失败了哪些一目了然

<p align="center"><img src="https://syncpan.top/images/docs/af-create-task.png" alt="自动追更-新建任务" width="680" /></p>

### 📂 文件浏览与管理 — 10 大网盘统一文件管理器

在应用内直接浏览和管理所有网盘中的文件，无需打开网页。10 大平台随时切换，一个界面管完所有网盘。

**使用场景：**
- 整理网盘文件：批量重命名、移动、删除、复制
- 查看文件内容：直接在应用内预览图片、播放视频、阅读文本
- 上传下载：本地文件直传网盘，云端文件一键下载到本地
- 创建分享链接：选中文件一键生成分享链接和提取码

**功能要点：**
- 目录浏览 + 面包屑路径导航，随时返回上级目录
- 文件操作：重命名、删除、移动、复制、新建文件夹
- 批量多选操作：底部浮出操作栏，批量分享/删除/移动/复制
- 🎬 **视频在线播放**：云端转码流媒体直供，应用内直接播放
- 🖼️ **图片预览**：灯箱模式全屏查看，支持前后翻页、缩略图加速加载
- 📄 **文本预览**：TXT、MD 等文本文件直接在应用内阅读
- ⬆️ **上传下载**：本地文件上传到网盘（进度面板）、网盘文件下载到本地（进度推送）
- 存储空间：实时显示已用容量和总容量
- 115 网盘专属：离线（云下载）任务列表随时查看

### 🚀 跨盘互传 — 网盘之间直接搬家

**全网少见的跨网盘文件直传能力**：选中源网盘的文件，指定目标网盘的目录，一键把文件从 A 盘搬到 B 盘，彻底告别「先下载到本地、再手动上传」的原始人操作。

**使用场景：**
- 网盘会员到期前，把资源批量迁移到另一个网盘
- 多个网盘之间重新分配资源，哪个空间大用哪个
- 把分散在各平台的资源统一归拢到一个主力盘

**功能要点：**
- **一源多目标**：一份文件可以同时分发到多个网盘账号
- **秒传探测优先**：先按文件哈希探测目标盘秒传，命中则瞬间完成、零流量消耗
- **传输引擎兜底**：未命中走下载直链 + 目标盘官方上传通道，Range 断点续传、直链失效自动重取
- **任务化管理**：互传任务持久化保存，支持暂停 / 恢复 / 取消 / 失败重试，中断后接着传
- **同名冲突策略**：跳过 / 覆盖 / 自动重命名，三种策略任选
- **传输前预检**：文件数、总体积、同名冲突提前告知，心里有数再动手
- **带宽限速**：全局下载限速，边传边用不卡网

- 一键「转存并分享」：将搜索到的资源保存到自己网盘并生成新的分享链接

### 📦 批量转存 — 多链接批量转存 / 多账号分发

一次性将多条分享链接中的文件批量保存到你的网盘，10 大网盘全支持。

**使用场景：**
- 一次性处理几十上百条分享链接
- 将多个来源的资源统一保存到自己的网盘
- 一份资源同时分发到多个账号

**功能要点：**
- 粘贴多行分享链接，自动解析
- **多目标账号**：一次选择多个目标账号，并行执行并汇总结果
- 实时进度显示，每条链接的转存结果一目了然
- 支持暂停/继续/取消，失败条目可单独重试
- 独立的防风控策略，可自定义操作间隔和批次暂停时间，**保存设置后运行中任务实时生效**

### 🔗 链接转换 — 分享链接批量「换主体」

将别人的分享链接转存后，用自己账号重新生成新的分享链接。资源整理党/分享者的利器：批量完成链接「换主体」，让资源真正变成自己的。

**使用场景：**
- 把收集到的资源整理后用自己账号重新分享
- 需要统一管理分享链接时使用

**功能要点：**
- 粘贴分享链接，自动解析
- 转存到目标账号后自动重新生成分享链接
- 支持批量转换、多目标账号
- 结果表格展示：源链接 → 新链接
- 支持暂停/继续/取消

### ✏️ 批量重命名 — 网盘文件批量改名神器

按规则批量修改网盘中的文件、文件夹名称。支持正则替换、序号命名、添加前后缀、修改扩展名，10 大网盘全支持。

**使用场景：**
- 批量删除文件名中的广告文字
- 给剧集文件添加序号
- 统一修改文件扩展名
- 批量添加前缀/后缀

**功能要点：**
- 支持递归子目录，可设置递归深度
- 可按类型筛选（只改文件/只改文件夹/全部）
- 重命名规则：正则替换、文本查找替换、序号命名、添加前后缀、修改扩展名
- 预览面板：先预览重命名结果，确认后再执行
- 支持暂停/继续/取消

### 📢 批量分享 — 批量生成分享链接

批量给网盘中的文件创建分享链接和提取码。适合资源分享者：整批文件一次生成分享，提取码和有效期统一配置，不必在网页里逐个操作。

**使用场景：**
- 一次性给多个文件生成分享链接
- 需要统一的提取码和有效期时批量设置

**功能要点：**
- 配置待分享的文件路径列表
- **分享层级自选**：递归分享时可选 1～5 层，只分享选中目录下的指定代际内容

## 常见问题

### 支持哪些网盘？

目前已支持 **10 大主流网盘**：百度网盘、夸克网盘、阿里云盘、UC 网盘、123 网盘、115 网盘、光鸭云盘、移动云盘（和彩云）、天翼云盘、迅雷网盘。文件浏览、分享转存、扫码登录、批量工具全平台对齐，更多平台持续接入中。

### 为什么操作之间有延迟？

网盘平台对频繁操作有风控限制。SyncPan 内置智能风控策略，会在操作之间加入随机等待、批次暂停等保护措施，防止账号被限或封禁。你可以在「设置 → 防风控策略」中调整延迟强度。

### 登录信息保存在哪里？安全吗？

所有账号 Cookie 和 Token 使用 AES-256-GCM 加密后存储在本地，密钥从你的机器指纹派生，不会上传到任何服务器。

### 免费版有什么限制？

SyncPan 核心功能免费使用。免费版每平台有账号数量与定时任务数限制，VIP / SVIP 会员可解锁更多账号、更多任务和内网穿透等高级功能。发帖、邀请好友都能免费获得会员时长。

### 跨盘互传会消耗本地流量吗？

优先进行「秒传探测」：目标网盘已有相同文件时直接秒传成功，**零流量**瞬间完成；未命中才走下载直链 + 上传通道，支持断点续传和带宽限速，传输中断可随时恢复。

### 支持跨平台使用吗？

SyncPan 是桌面应用，Windows、macOS、Linux 都能用。通过「内网穿透」功能，手机和平板的浏览器也可以在局域网内访问使用；绑定 QQ / 微信机器人后，聊天窗口也能远程指挥。

### 如何自动追更资源？

1. 在「自动追更」页面点击「新建任务」
2. 输入任务名称，设置定时规则（如每天执行一次）
3. 粘贴要监控的分享链接
4. 选择保存目标网盘和目录
5. 任务会在设定时间自动检查更新，有新内容时自动转存
