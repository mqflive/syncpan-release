## SyncPan 是什么？什么是盘同步？

**SyncPan（盘同步）** 是一款**免费桌面端网盘批量管理工具**，专为百度网盘和夸克网盘用户设计。它可以帮你：

- **自动追更**：监控分享链接，新内容自动转存到你的百度网盘或夸克网盘
- **批量转存**：一次性将多条百度网盘/夸克网盘分享链接中的文件批量保存
- **文件管理**：无需打开网页，在软件内直接浏览、重命名、删除、移动网盘文件
- **资源搜索**：搜索全网百度网盘和夸克网盘的分享资源，一键转存
- **批量分享与重命名**：批量生成分享链接，按规则批量修改文件名

支持 Windows、macOS、Linux 三大桌面平台。完全免费，数据加密存储在本地，不上传任何服务器。

## 百度网盘 / 夸克网盘 核心功能一览

### 🔄 自动追更 — 百度网盘夸克网盘定时转存

把关注的百度网盘或夸克网盘分享链接设为任务，有新内容时自动转存，省去每天手动检查。

- **定时调度**：每天/每周/每月定时执行，也可按分钟/小时间隔运行，支持 Cron 表达式自定义
- **增量转存**：已转存的文件自动跳过，只同步新增内容，不重复保存
- **文件过滤**：可只保存 mp4 等特定格式，排除不需要的文件
- **聚合任务**：多个分享链接组合成一个任务，统一管理调度
- **任务导入导出**：JSON 格式备份和迁移任务配置
- **转存日志**：每次执行详细记录成功和失败的文件

### 📂 网盘文件管理 — 百度网盘夸克网盘文件浏览器

在软件内直接管理网盘文件，无需打开网页端。支持百度网盘和夸克网盘随时切换。

- 目录浏览、面包屑路径导航
- 文件增删改查：重命名、删除、移动、复制、新建文件夹
- 批量多选操作：一次勾选多个文件，批量分享/删除/移动/复制
- 图片预览：全屏查看，支持前后翻页
- 文本预览：TXT、MD 等文本文件直接查看
- 存储空间：实时显示已用容量和总容量

### 🔍 全网网盘资源搜索

通过 PanSou 盘搜引擎搜索全网的百度网盘和夸克网盘分享资源。

- 关键词搜索全网网盘分享文件
- 按百度网盘 / 夸克网盘筛选结果
- 搜索结果关键词高亮标红
- 一键复制分享链接
- 一键「追更」：从搜索创建自动追更任务
- 一键「转存并分享」：搜索到的资源直接保存到自己的网盘

**豆瓣影视发现页**：浏览电影热榜、口碑榜、新片榜、电视剧热榜，从榜单跳转搜索网盘资源。

### 📦 批量转存 — 百度网盘夸克网盘链接批量保存

一次性将多条百度网盘和夸克网盘分享链接中的文件批量转存到你的网盘。

- 粘贴多行分享链接，自动解析
- 分别选择百度和夸克的目标账号
- 实时进度显示，每条链接的转存结果清晰可见
- 支持暂停、继续、取消
- 独立防风控策略，可自定义操作间隔

### 🔗 链接转换 — 百度网盘链接互转

将别人的百度网盘/夸克网盘分享链接转存后用自己账号重新生成分享链接。

- 粘贴分享链接自动解析
- 转存后自动生成新的分享链接
- 结果表格展示源链接 → 新链接
- 支持暂停、继续、取消

### ✏️ 批量重命名 — 网盘文件批量改名

按规则批量修改百度网盘和夸克网盘中的文件、文件夹名称。

- 正则替换、文本查找替换、序号命名
- 添加前缀/后缀、修改扩展名
- 支持递归子目录，可设置深度
- 先预览再执行，安全可控

### 📢 批量分享 — 网盘文件批量生成分享链接

批量给百度网盘和夸克网盘中的文件创建分享链接。

- 统一设置提取码和有效期
- 支持暂停、继续、取消
- 结果面板展示所有生成的分享链接

### 🗂️ 我的分享 — 查看分享记录

查看你在百度网盘和夸克网盘上创建的所有分享记录。

- 显示浏览量、下载量、转存次数
- 真实密码获取（百度网盘隐藏提取码）
- 支持排序、筛选、导出 CSV

### 🧹 广告清理 — 网盘广告文件批量删除

一键扫描并批量删除百度网盘和夸克网盘中混入的广告文件。

- 按关键词匹配广告文件
- 先扫描再确认，确认后才执行删除
- 支持递归子目录

### 🌲 目录树导出

将网盘目录结构生成树形图或列表，导出为 TXT 文件保存到本地。

## 下载安装 — 百度网盘转存工具免费下载

> 前往 [**Releases 页面**](https://github.com/mqflive/syncpan-release/releases/latest) 下载最新版。

### Windows

下载 `.exe` 安装包，双击运行即可。安装界面自动跟随系统语言。

### macOS

1. 下载对应芯片（Apple Silicon M1-M4 / Intel）的 `.dmg` 文件
2. 双击打开，将 **SyncPan** 拖入「应用程序」文件夹
3. 首次打开如提示"无法验证开发者"，在终端执行：

   ```bash
   xattr -cr /Applications/SyncPan.app
   ```

> 💡 Mac 用户也可用 Homebrew 安装：
>
> ```bash
> brew tap mqflive/syncpan https://github.com/mqflive/syncpan-release
> brew install --cask syncpan
> ```

### Linux

**AppImage（推荐，无需安装直接运行）：**

```bash
chmod +x SyncPan_*.AppImage
./SyncPan_*.AppImage
```

**Debian / Ubuntu：**
```bash
sudo dpkg -i syncpan_*_amd64.deb
```

**Fedora / RHEL：**
```bash
sudo rpm -i syncpan-*.x86_64.rpm
```

## 常见问题

### 这个软件安全吗？账号密码会泄露吗？

所有账号 Cookie 和 Token 使用 **AES-256-GCM** 加密存储在本地电脑，密钥从你的机器指纹派生，**不会上传到任何服务器**。软件完全离线可用。

### 为什么操作之间有延迟？

百度网盘和夸克网盘对频繁操作有风控限制。软件内置智能风控策略，自动调整操作节奏，防止账号被限或封禁。可在设置中调整延迟强度。

### 免费吗？有什么限制？

SyncPan 完全免费使用。免费版每平台有账号数量限制，VIP 会员解锁无限账号和更多定时任务。

### 能自动追剧吗？

可以。把百度网盘或夸克网盘的追剧分享链接设为任务，设置每天执行一次，有新集时自动转存到你的网盘。
